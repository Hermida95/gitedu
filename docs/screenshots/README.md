# Screenshots

Drop your own captures here, then uncomment the image block near the top of the
main [README.md](../../README.md). Suggested filenames:

- `graph.png` — main window with a populated graph (a few steps into the sandbox's guided lessons works great, no real repo needed)
- `command-preview.png` — the confirmation modal before a merge/rebase
- `interactive-rebase.png` — the interactive rebase editor
- `conflict.png` — the conflict resolution panel

See "Capturing screenshots" in the main README for exact steps.
